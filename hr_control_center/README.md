# HR01 人事控制中心

> 新人从这里开始。HR01 是人事系统的“看全局、做治理、给结论”模块，不是第二套人员主档。

## 这个模块做什么

- 汇总 HR02-HR18 已经形成的权威事实；
- 提供管理工作台、治理告警、跨域统计和待办入口；
- 只做 Projection/Read Model，跨域写操作必须回到事实所属模块。

## 目录怎么找

- `models/`：HR01 自己拥有的投影/治理数据；
- `services/`：工作台聚合、统计和治理规则；
- `api/`：接口序列化、权限和视图；
- `templates/`：HR01 页面；
- `tests/`：单元、接口和跨域回归；
- `module_contract.py`：模块编号、API 根、事实边界，改代码前先看它。

## 接口规则

新代码统一挂在 `/api/v1/hr`。`/api/hr/v1` 只作为迁移期兼容入口，不能继续扩展新能力。

## 重构红线

1. 不直接修改 HR02-HR18 的权威模型；
2. 不在 `AppConfig.ready()` 里注册 URL；
3. 不删除 migration 来“修绿”；
4. 删除旧文件前必须先确认无路由、无 import、无模板引用并有替代实现；
5. 管理页面首屏先给结论、风险和下一步，再给明细。
