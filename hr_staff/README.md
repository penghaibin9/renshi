# HR03 教职工主档

> HR03 是人员事实的主入口。新人要找“这个人是谁、基础档案是什么、历史更正怎么留痕”，从这里开始。

## 权威职责

- 教职工身份主档与稳定人员标识；
- 基础档案、受控更正和历史留痕；
- 向其他模块提供人员 Provider，而不是允许其他模块复制人员主表。

## 目录怎么找

- `models/`：人员主档事实；
- `services/`：档案更正、校验、生命周期规则；
- `api/`：接口层；
- `templates/`：人员页面；
- `tests/`：主档、权限、跨租户、历史事实测试；
- `module_contract.py`：本模块边界。

## 重构红线

1. 人员主标识不能因组织/岗位/合同变化而重建；
2. 历史事实不能被今天的修改覆盖；
3. 跨租户必须 fail-closed；
4. 外域需要写人员事实时通过 HR03 命令/服务边界，不直接 `.save()` HR03 模型；
5. 新 API 统一 `/api/v1/hr`。
