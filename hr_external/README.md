# HR08 外聘与外部人员

> HR08 管“不是正式编内教职工、但学校需要管理其聘用和业务身份的人”。不要把它做成 HR03 的第二套人员主档。

## 权威职责

- 外聘/外部人员业务身份；
- 外部用工或聘用案例、有效期、材料和业务过程；
- 通过 Provider 向其他域提供受控读取，通过命令/事件完成跨域交接。

## 目录怎么找

- `models/`：HR08 自己的事实；
- `services/`：业务规则；
- `providers/`：给其他模块读取 HR08 事实的稳定边界；
- `selectors/`：只读查询；
- `integrations/`：外部集成；
- `api/`：接口；
- `tests/`：模块和跨域回归；
- `module_contract.py`：模块边界。

## 重构红线

不复制 HR03 正式人员主档，不越域修改 HR07/HR11；tenant 缺失即拒绝；新 API 统一 `/api/v1/hr`。
