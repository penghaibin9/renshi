# HR08 外聘人员

这是 HR08 的模块入口。HR08 负责外聘、兼职、校外专家等非正式在编人员的身份、聘任、资质和评价事实。

## 小白先看这里

- `models/`：外聘身份、聘任、资质、评价等模型。
- `services/`：正式写操作。
- `selectors/`：人员、聘任和历史查询。
- `api/`：正式 API。
- `policies/` / `permissions.py`：规则和权限。
- `templates/` / `views/`：管理端页面。
- `tests/`：状态、权限、租户、历史和导入导出测试。

## 重构硬规则

1. 外聘人员与 HR03 正式教职工边界清晰，禁止重复事实来源。
2. 资质、聘任、评价历史必须保留有效期和审计。
3. tenant / permission fail-closed。
4. 无引用且与设计合同冲突的旧模型才允许删除。
5. 正式 API 统一 `/api/v1/hr/...`。
