# HR09 资质与双师认定

> HR09 回答“这个教师具有什么资格、证书或双师认定，它在什么时间有效”。

## 权威职责

- 资质、证书和核验事实；
- 双师认定案例、结果、复核和有效期；
- 为 HR10/HR12 等模块提供受控的资质读取。

## 目录怎么找

`models/` 放资质事实，`services/` 放认定/核验规则，`api/` 放接口，`templates/` 放页面，`tests/` 放测试，`module_contract.py` 放边界。

## 重构红线

不把 HR10 的培训经历复制成资质事实；不越域修改 HR03/HR10/HR12；tenant 缺失即拒绝；新接口统一 `/api/v1/hr`。
