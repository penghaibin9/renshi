# HR09 资格资质

这是 HR09 的模块入口。HR09 负责证书、职业资格、职称/资质认定等事实和有效期管理。

## 小白先看这里

- `models/`：资格、证书、认定和有效期模型。
- `services/`：新增、审核、续期、失效等写操作。
- `selectors/`：人员资质、到期预警和历史查询。
- `api/`：正式 API。
- `policies/` / `permissions.py`：规则和权限。
- `tests/`：有效期、越权、租户、重复事实和审计测试。

## 重构硬规则

1. 资格事实必须带来源、有效期和审计。
2. 不能因为当前证书更新而覆盖历史认定。
3. tenant / permission fail-closed。
4. 跨模块只提供 Provider/事件，不直接修改其他模块事实。
5. 正式 API 统一 `/api/v1/hr/...`。
