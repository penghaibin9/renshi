# HR11 考勤与假期

> HR11 回答“这个人在什么时间应出勤、实际发生了什么、请假与异常如何留痕”。人员身份归 HR03，人事异动归 HR06，考核结果归 HR12。

## 权威职责

- 考勤规则、班次、排班、工作日历；
- 打卡/签到、缺勤、迟到早退、异常与受控更正；
- 请假、销假、假期额度和全过程审计；
- 向考核等下游模块提供带时间语义的只读事实。

## 目录怎么找

`models/` 放考勤事实，`services/` 放计算与业务规则，`api/` 放接口，`templates/` 放页面，`tests/` 放单元/接口/时间边界/跨租户测试，`module_contract.py` 放模块边界。

## 重构红线

- 不能因为今天改排班规则，就重算并覆盖已经封存的历史考勤事实；
- 人工更正必须保留原值、原因、操作者和时间；
- 跨学校访问必须 fail-closed；
- 不直接修改 HR03/HR06/HR12 权威表；
- 新接口统一 `/api/v1/hr`。
