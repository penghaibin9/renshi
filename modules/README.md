## 状态只允许四种

- `主体待完成`：只有骨架或部分基础能力。
- `深化施工`：核心模型存在，主要业务链仍缺。
- `整合中`：模块能力较完整，正在补 UI/E2E/Provider。
- `主链可用`：已有真实链证据，但仍不等于生产上线。

每次开发只进入一个模块文件夹，按该 README 的验收清单工作。
