## 治理原则

1. **不修改 LICENSE**：许可证文本和适用要求继续以仓库根目录 `LICENSE` 为准。
2. **不重写 Git 历史**：保留原始提交、作者和来源链路。
3. **不为了改名破坏兼容性**：Python 包名、数据库表名、迁移标识等只有在有明确迁移方案时才调整。
4. **用户可见品牌统一为跃科**：页面标题、Logo、帮助链接、README 和面向客户的文案不再以 Horilla 作为产品身份。
5. **历史接管文档不作为当前状态依据**：当前实现状态以 `main` 代码和当前 CI/测试证据为准。
