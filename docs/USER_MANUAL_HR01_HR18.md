# 跃科高校人事系统用户操作手册（HR01～HR18）

## 零基础 3 分钟开始

第一次使用时不用先学习 18 个模块。登录后先到 **HR01 人事工作台 → 我要办什么**，直接输入“入职、续签、调动、资质、考核、工资、退休”等业务动作。进入业务页后，不清楚流程就点右下角 **办理助手**（快捷键 `Alt+K`），按“建议办理顺序 → 办理前准备 → 常见卡点 → 下一步入口”操作。

填写表单时优先看“必填”和“表单完成度”；提交失败时按红色缺失清单逐项补齐。遇到超时、权限、版本冲突时先按页面给出的下一步处理，不连续重复提交。正式审批、认定、考核、薪酬和人事结果始终以后端业务状态与回执为准。

本手册按系统冻结的 18 个业务域组织，不以采购参考中的非学历教育菜单替代高校人事模块。

| 模块 | 主要用途 | 上线验收重点 |
|---|---|---|
| HR01 | 人事工作台 | 统一入口、待办、异常、明细穿透 |
| HR02 | 组织机构与编制岗位 | 组织层级、岗位、数据范围联动 |
| HR03 | 教职工主档 | 权威身份、任职、教育经历、更正审计 |
| HR04 | 招聘与人才引进 | 招聘计划、申请、评审、Offer/handoff |
| HR05 | 入职 | 材料、核验、办理与正式入职事实 |
| HR06 | 人事异动 | 申请、审批、生效、撤销/纠正历史链 |
| HR07 | 合同与聘用 | 合同版本、签署/生效、材料权限 |
| HR08 | 兼职外聘教师 | 聘用、授权、任务联动与退出回收 |
| HR09 | 教师资格与双师型 | 资质、证据、有效期、续期、历史版本 |
| HR10 | 培训进修与企业实践 | 计划、报名、实践、成果、Excel 真导入 |
| HR11 | 考勤与请假 | 请假、冲突、考勤事实 |
| HR12 | 年度与聘期考核 | 规则版本、自动计算、确认/异议、归档 |
| HR13 | 职称评审 | 申报、材料、评审与结果事实 |
| HR14 | 岗位聘任 | 聘任流程与正式结果 |
| HR15 | 薪酬福利 | 薪酬事实、核算/导出权限与审计 |
| HR16 | 退休与离校 | 退休、交接、结算、协同、档案 |
| HR17 | 教职工服务 | 本人申请、补件、更正、进度 |
| HR18 | 人事数据中心 | 指标、历史口径、数据交换、重试/对账 |

所有导入、导出、附件下载、规则变更、权限调整和高风险确认动作均以系统实际权限/审计为准。出现无权限、数据范围不一致、接口失败或统计口径异常时，不允许绕过后台控制手工改库。
