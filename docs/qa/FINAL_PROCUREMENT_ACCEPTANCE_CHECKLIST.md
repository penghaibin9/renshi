# 高校人事系统最终采购级验收清单

## A. 源码与部署
- [ ] 完整源码、依赖锁、Docker/Compose、数据库 migration、配置模板齐全。
- [ ] `check --deploy`、迁移漂移、HR01～HR18 MySQL 回归通过。
- [ ] `/ready/` 返回 200；正式环境关闭调试/演示入口。

## B. 初始化与权限
- [ ] 生成学校初始化快照，核对组织、岗位、角色、权限、管理员、配置/字典、接口映射、migration 状态。
- [ ] 角色复制仅复制权限，不复制成员/组织数据范围。
- [ ] 教师本人、教研室/部门、学院、学校管理四级代表账号进行数据范围/操作/导出越权测试，越权应全部被拒绝。

## C. 业务与数据
- [ ] HR09 资质有效期、到期提醒、审核、历史版本/快照抽样通过。
- [ ] HR10 Excel PREVIEW→确认→正式写入→逐行结果/审计抽样通过。
- [ ] HR12 数据来源、规则版本、计算、确认/异议、退回、归档快照抽样通过。
- [ ] HR18 接口字段映射、同步状态、失败原因、自动/人工重试、幂等与对账抽样通过。

## D. 性能与安全
- [ ] `run_procurement_performance_probe.py` 以采购人认可的脱敏真实数据执行：并发 >=100；普通页面阈值 <=3000ms；复杂统计 <=5000ms；NORMAL/ANALYTICS 均 PASS。
- [ ] 登录、查询、导出、权限调整、资质、考核、接口同步和附件访问有必要审计。
- [ ] 附件、敏感字段、导出和跨组织访问权限抽样通过。

## E. 灾备、移交和运行
- [ ] 加密灾备创建→校验→隔离恢复→迁移检查通过。
- [ ] 开放学校移交包创建→SHA/Manifest 校验→第二空库恢复→逐表行数一致→Web ready 通过。
- [ ] 试运行 JSON 所有代表性流程 PASS 且采购人/供应商双方确认。
- [ ] 整改台账所有项目 CLOSED + PASS + ACCEPTED；如无问题，必须用明确 NO_ISSUES 记录，不接受空文件。

## F. 培训、接口与售后
- [ ] 至少完成 ADMIN、OPERATOR 两类培训并确认。
- [ ] 合同要求的真实外部接口逐项 PASS；不适用项有采购人/供应商双方确认和理由。
- [ ] 售后 SLA、用户手册、管理员/经办手册已交付。

## G. 最终证据包
- [ ] 执行 `build_procurement_acceptance_package.py`；只有结果 `COMPLETE` 且 `releaseCertificate=true` 才可作为源码之外的最终运行验收候选证据。
