# 采购参考 14 项与高校人事系统最终收口对照

> 来源：用户提供的 9 页《一站式非学历教育智慧前台建设项目采购清单》。本对照只吸收高校人事系统适用的共性能力，不伪造非学历教育专属业务。

| 采购项 | 高校人事系统处理 | 最终验收证据 |
|---|---|---|
| 1 门户应用 | 适用：HR01/HR17 统一入口、待办、业务穿透、角色菜单 | 工作台人工抽样、权限账号截图/记录 |
| 2 统一认证与组织权限 | 适用：RBAC、公司/组织数据范围；本轮修复精确 Permission 变更并支持复制角色权限 | 四级代表账号越权测试；真实 SSO 联调（如合同要求） |
| 3 基础配置/字典 | 适用：新增学校初始化快照，记录安全可交付配置 | initialization snapshot + SHA |
| 4 学校数据中台 | 共性能力适用：HR18 映射、同步、清洗/校验、重试、状态/错误；真实字段必须学校联调 | 外部接口 JSON + HR18 状态/重试证据 |
| 5 教师工作台 | 适用：HR01/HR17 教师本人数据与待办；不照搬非学历教育收入/课程人次 | 本人范围与待办穿透抽样 |
| 6 教研室/学院管理 | 适用为组织层级数据范围和审核；高校人事实际组织结构为准 | 部门/学院代表账号数据范围测试 |
| 7 学校驾驶舱 | 适用：HR18 全域人事数据中心、历史口径和明细穿透 | 复杂统计性能 + 指标抽样 |
| 8 教师资质 | 高度适用：HR09 资质、证据、有效期、审核、续期、历史版本 | 到期/续期/历史 as-of 抽样 |
| 9 教师积分激励 | **不直接适用**：采购项依赖非学历培训收入/课程人次；不得拿 HR12 分数或旧游戏化积分冒充 | 如学校另购则独立需求/规则/台账/双轨验收 |
| 10 三级考核 | 高度适用：HR12 规则版本、自动计算、确认/异议、退回、归档快照 | 代表样本双轨计算、流程进度、历史快照 |
| 11 省级平台对接 | 接口工程要求适用；具体平台只有合同包含并提供真实规范时才实施 | external integration machine evidence |
| 12 日志/安全/待办/附件 | 适用：审计、统一待办、附件权限、敏感信息控制 | 安全/附件/导出抽样 |
| 13 部署上线 | 适用：Docker/Compose、MySQL、初始化、运行回归、3s/5s/100并发门、完整交付 | runtime evidence + performance evidence |
| 14 售后运维 | 适用：SLA、开放移交、培训、数据可迁移 | SLA + handover + training + final pack |
