# 系统设置生产验收合同

> 适用范围：右上角用户菜单中的“系统设置”入口，以及由该入口进入的全部设置页面。
>
> 状态原则：只有同一精确提交 SHA 的 Chromium、权限、MySQL 与回归测试全部通过，才能标记为“已完成”。

## 1. 入口合同

1. 管理员必须通过生产登录表单建立真实 Session。
2. 必须点击页面右上角真实用户菜单，再点击可见的“系统设置”入口。
3. 入口不得是 `#`、空链接、`javascript:` 占位或仅展开但不导航的伪入口。
4. 入口必须到达同源、可解析、非 403/404/500 的设置落地页。
5. 普通业务角色不得因为知道 URL 而进入可写设置页面。

## 2. 页面合同

设置首页及其可见子页面必须满足：

- 路由真实存在，刷新不丢失；
- 页面无未捕获 JavaScript 错误；
- 设置 API 不得返回未处理的 4xx/5xx；
- 表单按钮、导航链接和保存动作不得是假按钮；
- 禁止使用 mock、静态 JSON 或仅前端回显冒充保存成功；
- 敏感字段不得把密钥、Token 或口令原文返回浏览器。

## 3. 保存与回读合同

至少选择一个低风险设置完成：

```text
打开设置页
→ 修改字段
→ 点击真实保存按钮
→ 后端写入成功
→ 页面刷新
→ 新值仍然存在
→ MySQL 中能够反查同一事实
```

验收不得通过直接创建数据库记录、调用 Django TestClient、注入 Session 或跳过浏览器按钮来替代。

## 4. 角色与租户合同

| 角色 | 入口 | 查看 | 修改 | 直接猜测 URL |
|---|---:|---:|---:|---:|
| 平台/系统管理员 | 允许 | 允许 | 按授权允许 | 允许 |
| 学校租户管理员 | 按租户授权 | 仅本租户 | 仅本租户 | 不得跨租户 |
| HR 普通业务人员 | 默认隐藏 | 按业务授权 | 禁止系统级修改 | 403/404 或只读 |
| 异租户管理员 | 仅本租户 | 仅本租户 | 仅本租户 | 目标租户对象必须隐藏 |

不能只隐藏菜单；服务端仍必须强制执行权限和租户边界。


每次验收至少保留：

```text

```

## 6. 失败分类与修复顺序

```text
入口不存在/占位
→ 路由不存在
→ 权限错误
→ 页面或 API 异常
→ 保存动作失败
→ 刷新后丢失
→ MySQL 未落库
→ 跨租户泄漏
```

禁止通过放宽权限、取消租户过滤、接受 409/403 为成功、删除保存断言或仅判断 HTTP 200 来“消红”。

## 7. 封板条件

系统设置只能在以下条件全部满足时封板：

- `System Settings Real Browser Gate` 绿色；
- `Quality / MySQL Contract` 绿色；
- 静态设置入口和 URL 合同绿色；
- 管理员真实保存与刷新回读绿色；
- MySQL 事实反查绿色；
- 普通角色和异租户边界绿色；
- 证据绑定同一精确提交 SHA；
- 文档索引记录代码、测试、工作流、证据和最后验证 SHA。
