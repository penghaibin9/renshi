# 系统设置页面与角色验收矩阵

本文件是系统设置施工清单，不以菜单存在或页面返回 200 作为完成依据。真实结果由 `System Settings Real Browser Gate` 的同一精确提交 SHA 证据回填。

## 验收对象

| 区域 | 必测内容 | 管理员 | 普通业务人员 | 租户边界 | 保存回读 |
|---|---|---:|---:|---:|---:|
| 右上角用户菜单 | 菜单展开、系统设置入口、退出登录 | 可见并可点击 | 按授权隐藏 | 不泄漏其他学校 | 不适用 |
| 设置首页 | 路由、导航、错误态、刷新 | 可访问 | 403/404 或只读 | 必须 | 不适用 |
| 学校/公司信息 | 名称、显示信息、时区等低风险项 | 按授权可改 | 禁止 | 必须 | 必须 |
| 角色与权限 | 角色列表、授权边界、职责分离 | 按授权 | 禁止 | 必须 | 必须 |
| 通知与邮件 | 开关、模板、发送配置 | 按授权 | 禁止 | 必须 | 必须；密钥不得回显 |
| 外观与主题 | 品牌、主题、Logo 引用 | 按授权 | 禁止 | 必须 | 必须 |
| 安全设置 | 登录、安全策略、会话策略 | 系统管理员 | 禁止 | 平台/租户分层 | 必须；敏感值遮罩 |
| 数据与审计 | 审计查看、导出、保留策略 | 按授权 | 只读或禁止 | 必须 | 写操作留审计 |

## 浏览器执行顺序

```text
管理员生产登录
→ 展开右上角用户菜单
→ 点击系统设置
→ 遍历设置首页可见导航
→ 检查每页 HTTP、DOM、Console、HR/设置 API
→ 修改一个低风险配置
→ 点击真实保存按钮
→ 刷新并回读
→ MySQL 反查
→ 普通角色重新登录
→ 验证菜单隐藏和直接 URL 服务端拒绝
```

## 强制失败条件

- 设置入口为 `#`、空链接或 `javascript:`；
- 点击入口只展开菜单、不进入设置页；
- 页面 403/404/500，或出现未处理 JavaScript 异常；
- 保存仅前端提示成功，刷新后丢失；
- 数据没有写入 MySQL；
- 普通角色可通过猜测 URL 修改系统配置；
- 一个学校的配置影响另一个学校；
- 密码、Token、密钥或 SMTP 凭据明文回显；
- 测试通过 Session 注入、TestClient 或直接造最终数据库事实绕过真实按钮。
