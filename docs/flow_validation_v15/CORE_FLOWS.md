# HR01–HR18 核心业务流程（V15）

## C01 首次建档 / 数据迁入（HR02 → HR03）
组织与岗位准备 → Excel/合法来源进入人员导入 → 行级校验 → Person → Staff → Employment → PRIMARY Assignment → 错误行/回执/审计核对。

## C02 招聘录用 → 入职交接（HR04 → HR05）
招聘计划/岗位 → 候选人/资格 → 评审结果 → 拟录用/公示 → Offer 创建、审批、签发、接受 → 幂等交接 HR05。

## C03 报到、材料、责任协同 → 正式人员（HR05 → HR03）
待报到 → 校本材料/任务 → 报到 → 材料上传与核验 → 责任任务与前置 → 正式激活 → Person/Staff/Employment/Assignment 回读 → 协同结案。

## C04 人事异动 → 任职事实更新（HR06 → HR03/HR02）
发起异动 → 冻结原事实 → 审批 → 生效 → 新任职/原任职关闭或并存 → 岗位容量提交 → 回读。借调挂职保留原岗时额外核对 FTE 剩余额度与预计返岗日。

## C05 合同 / 续签 / 终止（HR07）
合同起草/签署 → 版本冻结 → 到期/续签/变更 → 生效与历史版本保留 → 文档访问审计。

## C06 外聘人员（HR08）
外聘关系 → 权限/资源开通 → 任务/工作量 → 核验结算依据 → 续聘或退出 → 外部权限撤销；外部系统未配置时不伪造自动开通。

## C07 资格资质 ↔ 教师发展（HR09 ↔ HR10）
发展活动/企业实践/培训 → 正式核验事实 → HR09 资格规则取证 → 资质申请/审核/历史版本；来源身份无法确定时 fail-closed。

## C08 考勤月结 → 工资输入（HR11 → HR15）
考勤/请假/加班 → 月结快照 → PayrollTimeBasis → HR15 权威输入快照 → 后续算薪。考勤分钟不等于教学课时。

## C09 考核周期（HR12）
政策/周期 → 来源采集 → 计算 → 教师/组织确认 → 正式定稿 → 送达/确认 → 归档 → 历史依据冻结 → 更正保留旧版本。

## C10 职称评审 → 岗位聘任（HR13 → HR14）
材料/资格 → 专家评审/回避/表决 → 结果公示与异议 → 正式职称结果 → HR14 冻结职称依据 → 岗位竞聘/集体决定 → 正式聘任事实。

## C11 工资核算与支付（HR15）
人员薪酬制度 → 标准/个人核定/来源快照 → 试算与独立复核 → 正式核算 → 封账 → 支付指令/回执 → 工资单/财务对账 → 正向历史补差。复杂专项仍按 V8–V14 限制执行。

## C12 退休 / 离校（HR16）
离退发起 → 交接与阻塞项 → 正式生效 → append-only 离退/退休事实 → 工资停发与历史欠款边界 → 归档/返聘另建关系。

## C13 教职工本人服务（HR17）
认证本人 → 查看本人正式事实/工资摘要/离退事实 → 补件/更正申请 → 独立审核 → 正式域写回。本人不能自批，也不能直接编辑工资或聘用事实。

## C14 数据治理与报送（HR18）
指标/人口定义版本 → 权威来源采集 → 数据质量运行 → 历史 as-of 计算 → 冻结结果/证据 → 钻取/导出/报送。来源不可用与真实零值分开。

## 验证边界
- 当前可执行证据主要为 Django 服务/ORM/契约测试与 SQLite 隔离数据库；不是生产 MySQL、SSO、真实 Cookie/MFA 或外部系统联调。
- MySQL 专用触发器、行锁并发、完整 HR03/HR16/HR17/HR18 round2 场景仍需演示服务器的 MySQL 8.4 环境。
- HR09 全 HTTP 测试在当前沙箱缺少 djangorestframework 依赖，因此本轮使用其服务/provider 证据链回归；不把缺依赖记为产品失败或通过。
- 银行、税务、学校统一认证、邮件、一卡通等外部提供方未接入时保持“未配置/不可验证”，不伪造成功。
