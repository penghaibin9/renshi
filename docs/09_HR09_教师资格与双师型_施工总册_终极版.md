# 0. 五个三级模块冻结

```text
HR09 教师资格与双师型
├─ HR09-01 教师资格台账
├─ HR09-02 双师认定标准
├─ HR09-03 双师申报
├─ HR09-04 认定与评审
└─ HR09-05 复核与资格台账
```

五个工作区职责：

- **HR09-01 教师资格台账**：管理法定教师资格、职业资格/职业技能等级、非教师系列职称等可用于任教/认定的正式资格事实、核验、有效性与风险；
- **HR09-02 双师认定标准**：管理国家基本标准、省级规则包、学校实施细则、初中高三个层级、专业大类差异、破格条件、证据要求和规则版本；
- **HR09-03 双师申报**：教师个人/学院发起申报，系统自动聚合 HR03/HR10/教务等已核验事实并生成“申报证据包”；
- **HR09-04 认定与评审**：资格预审、形式审查、专家/委员会评审、回避、评分/投票、异议、结果确认；
- **HR09-05 复核与资格台账**：认定结果、生效/有效期、复核、升级、降级/撤销、到期、资格风险、历史查询和统计。

# 3. 国家制度硬边界

## 3.1 教师资格

现行《教师资格条例》明确教师资格分为多个类别，其中包括：

```text
中等职业学校教师资格
中等职业学校实习指导教师资格
高等学校教师资格
```

高校/职业院校系统必须把“资格类别”结构化。

教师资格认定属于行政/法定资格事实：

```text
TeacherQualification
```

不是学校内部“双师型”荣誉。

## 3.2 高校教师资格

高等学校实行教师资格制度。

系统应支持：

- 已取得教师资格；
- 认定申请中；
- 学校受委托认定场景；
- 外部认定机构；
- 证书核验；
- 被撤销/丧失等状态。

但 HR09 V1 重点是“资格事实管理”，不把完整国家教师资格考试/行政审批系统自行复制一遍。

# 4. 双师型国家基本标准硬边界

教育部 2022 年“双师型”教师认定通知明确：

- 主要适用于职业学校专业课教师（含实习指导教师）；
- 符合条件的公共课教师、校内其他实际承担教学任务人员、正式聘任的校外兼职教师等可参照；
- 设置 **初级、中级、高级** 三个层次；
- 国家制定基本标准；
- 省级教育行政部门制定本地标准；
- 各地各校标准不得低于国家基本标准；
- 可结合实际明确破格条件；
- 强调师德、教学能力、企业实践、产教融合、技术技能、专业建设、成果等。

因此系统模型必须是：

```text
National Baseline
        ↓
Provincial Rule Pack
        ↓
School Rule Pack
        ↓
Recognition Batch Frozen Rule Version
```

# 7. “相应能力水平”不能做成简单 if

国家标准中存在：

```text
职业资格/职业技能等级
非教师系列职务（职称）
或具有相应能力水平
```

因此系统必须支持：

```text
EQUIVALENCY_ROUTE
```

但等效能力必须：

- 有标准；
- 有证据；
- 人工评审；
- 有 reason；
- 有 committee decision；
- 有版本。

禁止：

```text
if teacher.seniority > 10:
    equivalent = True
```
