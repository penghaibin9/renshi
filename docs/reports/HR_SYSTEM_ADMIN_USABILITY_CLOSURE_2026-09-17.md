# 高校人事系统：系统管理与易用性收口报告

## 结论

HR01～HR18 业务侧易用性继续保持 R5 基线；本轮将系统管理也改造成任务优先入口，管理员不再需要先理解原始设置菜单结构。

## 主要整改

- 系统管理首页：账号、角色、组织、岗位、参数、审计、邮件、接口一屏进入。
- 口语搜索：“开账号 / 配角色 / 加部门 / 查日志 / 邮件 / 接口”等直接命中。
- 账号权限概况：启用/停用账号、未分角色、角色数量、直接授权账号。
- 首次上线 6 步清单：仅作实施导航，明确不等同验收。
- 管理员办理助手：12 个高频问题，答案只解释流程和边界，不读取敏感业务字段。
- 角色权限风险预览：显示已授权数量和 Delete 高风险数量。
- 高风险 Delete 权限二次确认，降低误授权。
- HR18 入口按真实 `hr.data.exchange` 权限显示。
- 运维能力说明：生产备份、学校移交、初始化快照、最终验收均明确“服务器执行/真实证据”，不把源码存在冒充运行通过。
