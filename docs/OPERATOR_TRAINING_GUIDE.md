# 高校人事系统经办人员培训手册

目标：零基础经办人员能够按 HR01～HR18 的真实状态机办理业务，不通过手工改状态、跳过审批或覆盖历史事实完成工作。

## 第一课只教三件事

1. 不背 HR 编号：从 HR01 的“我要办什么”搜索要办的业务。
2. 不会办就点“办理助手”：先看顺序、材料、卡点和下一步。
3. 报错先看系统给出的下一步：尤其超时时先刷新状态，避免重复提交。

培训时先用“新教师入职 → 被退回补材料 → 重新提交”的完整任务演练，再讲模块结构。这样经办人员先形成任务心智，再学习专业菜单。

## 高频操作

- 从统一工作台进入本人待办、组织待办和异常事项；从汇总指标穿透到业务明细。
- HR03 教职工主档：查询、本人补正/更正、材料补充和权威事实回读。
- HR06/HR07：异动、合同与聘用按审批/生效/更正链办理。
- HR09：资质新增、审核、续期、到期风险和历史证据查看。
- HR10：发展计划、培训、企业实践、Excel 预览→确认→正式写入；失败行不得冒充成功。
- HR12：考核数据来源、规则版本、计算过程、确认/异议、退回、归档快照。
- HR16：离退审批、交接、结算、协同回执和正式离校档案。
- HR17：本人申请、补件、更正与处理进度。
- HR18：数据查询、统计、接口同步状态和失败重试。

经办培训必须包含至少一条正常流程、一条退回/补正流程和一条权限不足场景。
