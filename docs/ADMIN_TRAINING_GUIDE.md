# 高校人事系统管理员培训手册

目标：管理员能够独立完成上线初始化、账号/角色/数据范围、字典参数、接口状态、审计、备份恢复、学校移交与验收证据管理。

## 必训任务

1. 使用 `export_school_initialization_snapshot` 导出当前初始化快照并核对组织、岗位、角色、管理员、配置、接口映射和 migration 状态。
2. 创建角色、复制已有角色权限；验证复制只复制 Permission，不复制成员和学校/组织数据范围。
3. 调整组织/角色后，用不同身份重新登录核对菜单、操作、数据范围和导出权限即时生效。
4. 在 HR18 查看接口映射、最近同步、失败原因；演练单条/批量人工重试，并确认原失败记录仍保留。
5. 查询安全审计和重要业务审计；验证附件查看/下载受权限控制。
6. 运行生产验收计划、灾备校验、隔离恢复、开放学校移交校验。
7. 熟悉严重故障响应、回滚和证据留存要求。

培训完成必须写入 `TRAINING_RECORD_TEMPLATE.csv` 对应格式并由参训人员确认。
