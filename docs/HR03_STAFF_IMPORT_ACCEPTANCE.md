## 学校办理路径

学校已有真实 HR02 组织和空缺岗位 → HR03 名册 → 下载 xlsx 模板 →
填写已核验在职人员 → 上传预检 → 下载原文件行号对应的错误清单 →
勾选确认提交有效行 → 刷新名册/任务 → 任职归属及 HR02 岗位占用回读。
新招聘走 HR05，外聘走 HR08。导入不创建登录账号，不伪造 Employee，
不切换学校 Authority 状态，不代替编制方案或考核薪酬制度审批。

## 同一份正式业务数据

复用 ImportService、PersonIdentityService、StaffMasterService、EmploymentService、
AssignmentService，不增加人员/部门/导入任务数据库。组织与岗位通过当前学校的
稳定编码查询，不信任上传文件的租户编号、数据库 ID 或旧部门映射。
同文件/本校工号重复、证件重复、姓名生日疑似重复均进入人工核对，不覆盖原档案。
已有复杂任职或后续版本的迁移保守拒绝，请走正式任职分段办理。

## 文件边界

xlsx 工作表必须名为“人员导入”；同时支持 UTF-8/BOM CSV。
限制：5 MB、5000 数据行、32 MB 解压内容和 200 个压缩成员。
工号、证件号、组织与岗位编码必须按文本填写，不猜测恢复被 Excel 丢失的数字。
拒绝重复/未知表头、表头外数据、公式、Excel 错误、宏、外部引用和嵌入对象。
检查实际 XML 行列坐标及 worksheet 关系，不只依赖可被错误声明的 dimension；
额外行列、重复坐标不得被静默截断。读取前 reset_dimensions，保留原文件行号。

模板为“人员导入 / 填写说明 / 本校组织岗位”三表。参考最多 2000 个岗位，
不是容量承诺；没有对应查看权限时只提供格式，不附本校台账。
错误工作簿只含行号、字段、错误代码和安全说明，不附证件或生日；文字强制文本类型。
新上传证件值在暂存前使用现有加密服务并绑定学校/任务/行号。
历史明文暂存清理、保留期限与密钥轮换不是本次已完成范围。

## 事务、并发与中断

预检原子保存暂存任务、250 行一批的校验结果及预检审计；不写正式人员。
预检只作参考，不锁定容量。提交逐行再次核对版本、有效日期、组织归属、
人数/工作量、未来任职区间和有效 HELD 预占。正式任职创建/切换共用岗位行锁。
每行 Person/Identity/Staff/Relationship/Assignment/事件/审计及提交标记一起成功或回滚。
不同数据行独立处理，不把整文件包装成长期事务。

每次 HTTP 最多 100 行，8 秒软预算在行之间检查，不承诺单个 SQL 不超时。
未完成回 READY_TO_COMMIT，保留原任务与成功行；再次勾选后继续下一段。
终态重复提交只回读；过期执行者由任务令牌和每行锁阻断。沿用 30 分钟失联租约。
网络失败只表示结果未知，要求读取原任务，不能自动重传整批或声称已全部回滚。

## 访问与审计

上传/提交/状态/错误下载检查当前学校及 `hr.staff.import`，并限定 SCHOOL 范围。
新任务由上传者持有，同校其他导入员不可直接读写；旧无上传者标记的任务暂按原权限行为。
只读用户请求写入 403；另一学校访问任务 404。标准 CSRF 校验不绕过。
预检、每行正式提交、完成、错误清单下载留审计；各正式服务收到实际 actor。
异常不将 SQL、密钥、证件值或数据库细节返回浏览器。
