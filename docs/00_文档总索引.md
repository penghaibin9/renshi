## 四、文档层级关系图

```text
00 全局宪法（最高）
   ├── 99 施工总控路线图（PATCH/波次/Gate）
   │      └── HR01-HR18 复审报告（P0/P1 补丁清单）
   │             └── 01~18 各模块施工总册（唯一业务事实源）
   │                    ├── docs/hr/* 各模块 S0 输出物（GAP/TASK/RISK/契约）
   │                    ├── docs/hr/legacy/* Legacy 映射
   │                    └── docs/hr/总控/并行施工总控台账（跨窗口同步）
   └── renshi/ 真实代码（唯一执行事实源）
```

## 五、阅读顺序建议

1. **新接手总控**：00 → 99 → 复审报告 → 台账
2. **新开某模块窗口**：00 → 该模块总册 → 对应 `legacy/*Mapping` → 对应 `*_GAP_MATRIX` → `*_TASK_TREE`
3. **验收某模块**：`*_TASK_TREE`（阶段清单）→ `*_Sxx_ACCEPTANCE/封板评估` → 台账 §8 对应验收标准
4. **跨域契约核对**：99 §6-8（API/Permission/Event Registry）+ 复审 §18（Canonical Freeze）+ 台账 §2（里程碑）
