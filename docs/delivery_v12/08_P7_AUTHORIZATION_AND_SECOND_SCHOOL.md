## 第二学校复制，不复制第一学校数据

| 检查点 | 通过条件 |
|---|---|
| 源码与许可 | 同一受控版本、依赖和原许可，不复制客户专属未经授权代码 |
| 环境隔离 | 新的域名/数据库/文件目录/任务/备份边界按原部署架构确认；不强行改变原租户模型 |
| 账号与秘密 | 新学校独立账号、密钥与权限；不沿用首校管理员密码、令牌、MFA或存储凭证 |
| 校本模板 | 仅复制获准的空结构或可复用配置；经第二校经办/发布人核对并重新发布 |
| 数据清洁 | 不带首校人员、材料、工资、审计、消息、文件、缓存、回执或任务 |
| 组织与映射 | 第二校按自己的组织、岗位、原部门映射和生效日建立，不能照抄首校ID |
| 接口 | 每个学校重新授权和验证，不沿用第一校SSO/财务连接 |
| 回归 | 第二校样本复做P2–P5与同人链；负例校验互不读取 |
| 交付 | 配置、操作、验收与支持责任由第二校真实签认 |

“复用软件”不等于“复制第一所学校的整库备份”。当前数据库/租户结构沿用原系统，不在本轮擅自改成新的一校一库架构。
