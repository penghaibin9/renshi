## 文件与原始证据

项目目录按 `01_scope / 02_environment / 03_import / 04_journey / 05_security_restore / 06_training / 07_acceptance / 08_support` 保存。源数据和秘密目录另受限存放，不放入普通截图册。文件命名带日期、场景、角色和版本，保留原日志及失败后修正记录。

对于服务端数据核对保留HTTP结果、数据库事实和审计三类；对文件另外保留字节校验；对客户活动必须有真实参与者确认。技术哈希只说明文件版本，不自动证明其内容真实或已签字。

项目Excel中“真实环境通过/待校方确认”等状态需对应证据，不能仅更改下拉框。尚未发生的客户活动全部保持空白或待确认。
