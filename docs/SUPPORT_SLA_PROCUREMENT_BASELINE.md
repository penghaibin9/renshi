# 跃科高校人事系统售后服务与运维保障基线

> 这是依据采购参考文件固化的**最低验收基线**。正式合同如约定更高标准，以正式合同为准；不得用本文件降低合同责任。

## 1. 质保与响应

- 免费质保期：最终验收合格之日起不少于 1 年。
- 严重故障：30 分钟内响应，2 小时内提供处置方案。
- 一般功能故障：2 小时内响应。
- 普通咨询、参数和配置问题：1 个工作日内响应。
- 质保期内学校组织、权限、规则、统计口径以及已接入接口的合理小幅调整，按合同范围提供配置、映射和适配支持。
- 质保期后年度运维服务费基线：原则上不高于合同金额的 10%，重大新增功能和新增第三方商业授权另行确认。

## 2. 事件闭环

每个事件至少记录：事件编号、影响范围、严重级别、发现时间、响应时间、临时处置、根因、永久修复、验证结果、学校确认、关闭时间。严重事件必须保留恢复点、审计和回滚证据。

## 3. 数据与供应商退出

学校业务数据、数据字典、字段映射、数据库结构、接口文档、部署配置和学校专属规则配置按合同归属移交。系统提供开放格式学校移交包；不得以专有格式、加密字段或封闭接口阻止迁移。字段加密所需密钥材料按独立安全通道交接，不得把密钥直接塞入移交包。
