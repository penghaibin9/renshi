# HR02 组织与岗位

> 新人从这里开始。HR02 回答“学校现在有什么组织、岗位，它们在什么时候有效”。

## 权威职责

- 院系/部门等组织单元；
- 岗位、岗位编制和组织岗位关系；
- 组织与岗位的有效期历史，统一使用 `[effective_from, effective_to)`；
- 为 HR03 及后续模块提供组织岗位 Provider，不让其他模块复制一套组织表。

## 目录怎么找

`models/` 放事实模型，`services/` 放业务规则，`api/` 放接口，`templates/` 放页面，`tests/` 放测试，`module_contract.py` 是本模块边界入口。

## 接口规则

新接口统一 `/api/v1/hr`；旧 `/api/hr/v1` 仅兼容，不新增能力。

## 重构红线

- 今天改组织不能让历史任职记录跟着漂移；
- 跨租户查询必须 fail-closed；
- 不允许 HR03/HR06 等模块直接改 HR02 表；
- 不删迁移历史，不靠默认学校兜底。
