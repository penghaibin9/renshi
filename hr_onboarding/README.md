# HR05 入职办理

> HR05 接住 HR04 的录用结果，把“准备入职”推进为“手续完成并可以进入正式人事链”。

## 权威职责

- 入职案例、材料、核验、任务和办理状态；
- 录用结果到人员主档/合同域之间的受控交接；
- 入职过程的失败、退回、重试和审计。

## 目录怎么找

`models/` 放入职事实，`services/` 放流程规则，`api/` 放接口，`templates/` 放页面，`tests/` 放测试，`module_contract.py` 放模块边界。

## 重构红线

- 不直接越域保存 HR03/HR07 模型；
- 一个入职动作重试不能产生两个人员或两份合同；
- RETURN 与 REJECT 分开；
- tenant 必须显式传递，缺失时 fail-closed；
- 新 API 统一 `/api/v1/hr`。
