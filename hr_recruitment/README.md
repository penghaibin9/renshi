# HR04 招聘管理

> HR04 负责“从用人需求到录用决定”，但录用不等于已经成为正式教职工。

## 权威职责

- 招聘需求、计划、职位发布；
- 候选人、简历、筛选、面试/评审；
- 录用决策与招聘过程审计；
- 录用完成后向 HR05 发起正式交接。

## 目录怎么找

`models/` 事实，`services/` 招聘规则，`api/` 接口，`templates/` 页面，`tests/` 测试，`module_contract.py` 模块边界。

## 重构红线

- HR04 不直接创建 HR03 正式人员主档；
- HR04 不直接写 HR05/HR07 的权威表；
- 录用、退回、拒绝必须是不同业务语义；
- 任何学校范围数据都必须携带 tenant；
- 新 API 统一 `/api/v1/hr`。
